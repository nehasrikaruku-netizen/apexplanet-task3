## 📌 Project Overview
The **Expense Tracker Web Application** is a CRUD-based project developed using **PHP and MySQL** under XAMPP server.  
It helps users to manage daily expenses by allowing them to **add, view, edit, and delete expense records** efficiently.

This project was developed as part of **ApexPlanet Web Development Internship – Task 2**.

---

## 🎯 Features

- ➕ Add new expense records
- 📄 View all expenses in a structured table
- ✏️ Edit existing expense details
- ❌ Delete expense entries
- 🗃️ MySQL database integration
- ⚡ Simple and responsive UI
- 🔐 Basic validation and error handling
- 📊 Clean dashboard-style layout

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3  
- **Backend:** PHP (Core PHP)  
- **Database:** MySQL (phpMyAdmin)  
- **Server:** XAMPP (Apache + MySQL)
